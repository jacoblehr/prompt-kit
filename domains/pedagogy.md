# Lens: pedagogy

Teaching and learning lens for explanations, curricula, tutorials, training, assessment, feedback, and practice design.

## Use when
The task involves helping someone understand, practice, remember, transfer, or demonstrate a skill or concept.

## Adds
- Learner starting point, misconceptions, prerequisites, and cognitive load.
- Learning objective, practice loop, feedback mechanism, and assessment signal.
- Sequencing from concrete examples to abstraction.
- Transfer tasks that show whether learning generalizes.
- Adaptation for different levels of prior knowledge.

## Watch for
- Explaining too much before the learner acts.
- Confusing exposure with mastery.
- Skipping misconceptions or prerequisite gaps.
- Using assessment that only tests recall when transfer matters.
